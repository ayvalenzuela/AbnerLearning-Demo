# Rotary filler F-200 (F-200) - Service manual (fictional)

## F-200 / E14 - Low fill weight
Alarm E14 on the F-200 means: low fill weight.
Likely causes, in the order the manufacturer recommends checking them:
1. [F200-E14-C1] Product supply pressure low. Steps: Check header gauge reads 2.0-2.5 bar. Inspect supply pump strainer. Sensor sign: supply_pressure_bar below 2.0.
2. [F200-E14-C2] Clogged nozzle screen. Steps: Lock out. Remove nozzle, clean screen in warm caustic, refit.
3. [F200-E14-C3] Fill valve seat wear. Steps: Lock out. Inspect valve seat for scoring; replace seat kit FK-14.
4. [F200-E14-C4] Load cell calibration drift. Steps: Run calibration with 500 g test weight from the HMI service menu. Sensor sign: loadcell_zero_g above 5.

## F-200 / E22 - Bowl level high
Alarm E22 on the F-200 means: bowl level high.
Likely causes, in the order the manufacturer recommends checking them:
1. [F200-E22-C1] Level probe fouled. Steps: Clean level probe tip; verify reading against sight glass.
2. [F200-E22-C2] Inlet valve stuck open. Steps: Cycle inlet valve from HMI; replace actuator if it does not close. Sensor sign: inlet_valve_pct above 90.
