# Capper C-40 (C-40) - Service manual (fictional)

## C-40 / E31 - Cap torque low
Alarm E31 on the C-40 means: cap torque low.
Likely causes, in the order the manufacturer recommends checking them:
1. [C40-E31-C1] Clutch slip from worn magnets. Steps: Measure static torque with gauge; replace clutch magnet set. Sensor sign: torque_nm below 1.6.
2. [C40-E31-C2] Chuck insert worn. Steps: Inspect rubber chuck inserts; replace if glazed.
3. [C40-E31-C3] Wrong cap lot (liner thickness). Steps: Check cap lot against spec sheet; quarantine lot if out of spec.

## C-40 / E35 - Cap feed jam
Alarm E35 on the C-40 means: cap feed jam.
Likely causes, in the order the manufacturer recommends checking them:
1. [C40-E35-C1] Cap chute misaligned. Steps: Realign chute to the chuck turret with gauge block CG-2.
2. [C40-E35-C2] Sorter bowl speed too high. Steps: Reduce sorter speed to 70 percent and observe for 10 minutes. Sensor sign: sorter_speed_pct above 85.
