  • RAG (retrieval-augmented generation) looks up relevant passages in your own files first, so answers can point to a source you can check.
  • An agent is a model that can call tools, such as search, email or a database, over several steps. Limit what it can change and ask for confirmation before risky actions.
  • Generative models can produce fluent answers that are wrong, so the "costly?" question comes before choosing an approach.

Key takeaway: use the simplest tool that works. Plain automation for fixed rules, RAG for your own documents, agents only when it must act, and a human check whenever mistakes are costly.
